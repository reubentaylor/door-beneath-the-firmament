# The Door Beneath the Firmament

An adventure module for the unofficial **FLAIL** system for Foundry VTT.

This is a conversion of a funnel designed for 4-6 level 1 PCs with hirelings.

## Installation

1. In Foundry VTT, go to **Add-on Modules → Install Module**.
2. Paste this into the **Manifest URL** field at the bottom of the window:

```
   https://github.com/reubentaylor/door-beneath-the-firmament/releases/latest/download/module.json
```

3. Click **Install**.

Foundry will offer updates automatically when new versions are released.

## Requirements

- Foundry VTT v[12] or later
- The unofficial FLAIL game system for Foundry VTT

## Using the Adventure

1. Create or open a world using the FLAIL system.
2. Go to **Manage Modules**, enable **The Door Beneath the Firmament**, and save.
3. Open the **Compendium Packs** tab and import the adventure.
